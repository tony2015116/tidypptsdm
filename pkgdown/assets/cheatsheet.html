安装与一次巡检

# install.packages("pak")
pak::pak("tony2015116/tidypptsdm")
library(tidypptsdm)

mon <- run_monitor("D:/nedap/exports", days = 7)
mon$alerts               # 最后一天的警报
out <- file.path("D:/nedap/monitor",
                 format(mon$settings$end_date))
write_monitor_report(mon, out, open = TRUE)
write_monitor_tables(mon, out)  # monitor.xlsx

示例数据：tidypptsda::nedap、tidypptsda::fire。

输入数据 data =

所有函数都接受以下任一种，内部自动调用 read_station() 和 prep_visits()：

  • 导出文件所在的文件夹或文件路径；
  • 已读入 R 的原始导出数据（如 tidypptsda::nedap）；
  • read_station() 或 prep_visits() 的结果。
# 列名与默认格式不同：先写格式文件再读
tidypptsda::station_format("fire", file = "fmt.txt")
raw <- read_station("导出/", station = "fire",
                    format = "fmt.txt")
mon <- run_monitor(raw)
  • 单位统一：采食 g、体重 kg（0 视为未称重）、时长 s；未读到耳标的访问保留为 identified = FALSE；转栏的猪归到正确的测定站。
  • station = "nedap" / "fire"，默认自动判断。传入的数据不会被修改。

监控窗口 run_monitor()

run_monitor(data, days = 7, end_date = NULL,
            house_width = 1, low_feed_kg = 0.5,
            max_unidentified_pct = 5,
            max_feed_drop_pct = 30, iqr_k = 1.5,
            station = NULL, verbose = 1)
  • 窗口 = 截至 end_date 的 days 天（含首尾）。
  • end_date 默认是数据的最后一天；最后一天就是今天时取昨天（当天数据不完整）。也可指定 "2024-05-20"。
  • house_width：测定站编号前几个字符为栋号（1 时 203 属于栋 2）。
  • verbose：0 不输出，1 摘要，2 详细。

结果 mon <- run_monitor()

元素内容
stations每台测定站每天一行
houses每栋每天一行
pigs每头猪每天一行，无访问的日子也在
pig_summary每头猪一行：低采食天数、无访问天数、最后一天的状态
hours最后一天每台测定站每小时一行
alerts最后一天的警报
visits窗口内的访问记录
settings参数和窗口

窗口内每个单位每天都有一行，没有访问时计数为 0、其余为 NA，停机的站、不吃料的猪不会“消失”。列名后缀即单位：_kg、_h、_min、pct_（%）、n_（计数）。

日表 单独计算

monitor_stations(data, days = 7, end_date = NULL,
                 iqr_k = 1.5)
monitor_houses(data, days = 7, house_width = 1)
monitor_pigs(data, days = 7, low_feed_kg = 0.5)
monitor_hours(data, date = NULL)   # 0–23 时
测定站的列含义
n_pigs有识别访问的猪数
n_visits全部访问（含未识别）
pct_unidentified未读到耳标的访问 %
occupation_h测定站被占用的时间
feed_kg / feed_per_pig_kg采食量 / 头均采食量
weight_kg各猪当天体重中位数的平均
pct_weight_outlier超出 Tukey 界限（iqr_k）的体重 %

猪的 status：ok low_feed（< low_feed_kg）no_visit。窗口前 14 天内有访问的测定站也会列出，停机的站显示两周。

宽表 wide_table(x, value)

wide_table(mon$stations, "feed_kg")
wide_table(mon$pigs, "feed_kg")

把日表的一列变成“单位 × 日期”的宽表，和 Excel 里看到的一样；计数、kg、时间类的列加 total，其余加 mean。

警报 mon$alerts

type级别条件（默认）
station_downdanger测定站一整天没有任何访问
pig_no_visitdanger窗口内出现过的猪当天没有访问
unidentifiedwarning未识别访问 > max_unidentified_pct = 5%
feed_dropwarning采食量比前几天平均低 > max_feed_drop_pct = 30%
pig_low_feedwarning猪当天采食 < low_feed_kg = 0.5 kg
  • 列：level（danger 在前）、type、location、responder、value（触发值）、message。
  • 停机测定站上的猪不再逐头报警，由一条 station_down 说明（括号内为受影响猪数）。

作图 plot_monitor(x, type, locations)

type内容
"trend"猪数、访问、未识别 %、占用时间、采食、头均采食和体重的逐日变化；体重带为最轻到最重的猪，无访问的日子标红
"intake"堆叠柱状图，每头猪一种颜色：上图占当天总采食 %，下图采食 kg；图例标 [no visit]、[low feed]
"weight"每天体重的箱线图，红点在须线以外
"hours"最后一天每小时的访问、占用时间、采食

p$plot[[1]]

HTML 报告 write_monitor_report()

write_monitor_report(mon, path, title = NULL,
                     locations = NULL, open = TRUE)
  • 写出 index.html 和 img/；文件夹可整体拷贝或压缩，离线打开。
  • 第一页总览：最后一天的站数、猪数、访问、采食、警报，以及全部测定站和栋的表格。
  • 之后每站一页：警报、趋势图、采食堆叠图、猪只表、体重箱线图、分小时图。
  • 方向键翻页；搜索框输入耳标号，跳到这头猪所在的测定站。

每天定时运行 schedule_monitor()

install.packages("taskscheduleR")      # Windows
schedule_monitor(
  folder  = "D:/nedap/exports",   # 导出文件夹
  out_dir = "D:/nedap/monitor",   # 每天一个子文件夹
  time = "07:30",
  days = 7, house_width = 1)      # 传给 run_monitor()
# 删除任务
taskscheduleR::taskscheduler_delete(
  "tidypptsdm_monitor")
  • 写出脚本 tidypptsdm_monitor.R（在 out_dir，可用 script_dir 改），结果写到 out_dir/<最后一天>/。
  • Linux / macOS：打印一行 crontab，自己加进 crontab -e。
  • register = FALSE 只写脚本，可先检查或手动 source()。
  • 每次都重新读取整个文件夹；早已结束的批次可移走以加快速度。

Install and run once

# install.packages("pak")
pak::pak("tony2015116/tidypptsdm")
library(tidypptsdm)

mon <- run_monitor("D:/nedap/exports", days = 7)
mon$alerts               # last day
out <- file.path("D:/nedap/monitor",
                 format(mon$settings$end_date))
write_monitor_report(mon, out, open = TRUE)
write_monitor_tables(mon, out)  # monitor.xlsx

Example data: tidypptsda::nedap, tidypptsda::fire.

Input data =

Every function accepts any of these and calls read_station() and prep_visits() itself:

  • a folder or files of station exports;
  • raw exports already in R (e.g. tidypptsda::nedap);
  • the result of read_station() or prep_visits().
# other column names: write a format file first
tidypptsda::station_format("fire", file = "fmt.txt")
raw <- read_station("exports/", station = "fire",
                    format = "fmt.txt")
mon <- run_monitor(raw)
  • Units: feed g, weight kg (0 = not weighed), durations s. Visits without an ear tag are kept as identified = FALSE; pigs that moved are assigned to the right station.
  • station = "nedap" / "fire", detected by default. The input is never modified.

Window run_monitor()

run_monitor(data, days = 7, end_date = NULL,
            house_width = 1, low_feed_kg = 0.5,
            max_unidentified_pct = 5,
            max_feed_drop_pct = 30, iqr_k = 1.5,
            station = NULL, verbose = 1)
  • Window = the days days ending on end_date, both included.
  • end_date defaults to the last day of the data, or yesterday when that is today (today is incomplete). Or set it: "2024-05-20".
  • house_width: leading characters of the station ID that form the house (1: station 203 is in house 2).
  • verbose: 0 silent, 1 summary, 2 details.

Result mon <- run_monitor()

housesone row per house and day

Every unit has a row for every day of the window: counts are 0 and other columns NA without visits, so idle stations and pigs that stop eating do not disappear. The suffix is the unit: _kg, _h, _min, pct_ (%), n_ (count).

Wide tables wide_table(x, value)

wide_table(mon$stations, "feed_kg")
wide_table(mon$pigs, "feed_kg")

One column of a daily table as a unit × date table, as in Excel; counts, kg and times get a total, other columns a mean.

HTML report write_monitor_report()

write_monitor_report(mon, path, title = NULL,
                     locations = NULL, open = TRUE)
  • Writes index.html and img/; copy or zip the folder and open it offline.
  • First page: stations, pigs, visits, feed and alerts of the last day, and tables of all stations and houses.
  • Then one page per station: alerts, trend, intake bars, pig table, weight box plot and hours.
  • Arrow keys turn the pages; type an ear tag in the search box to jump to its station.

Run every day schedule_monitor()

install.packages("taskscheduleR")      # Windows
schedule_monitor(
  folder  = "D:/nedap/exports",   # station exports
  out_dir = "D:/nedap/monitor",   # one folder per day
  time = "07:30",
  days = 7, house_width = 1)      # run_monitor() args
# delete the task
taskscheduleR::taskscheduler_delete(
  "tidypptsdm_monitor")
  • Writes the script tidypptsdm_monitor.R (in out_dir, or script_dir); results go to out_dir/<last day>/.
  • Linux / macOS: prints a crontab line to add with crontab -e.
  • register = FALSE only writes the script, to check it or source() it by hand.
  • The whole folder is read each time; move finished batches elsewhere to keep it fast.
